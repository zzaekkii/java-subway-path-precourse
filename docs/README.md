# java-subway-path

## 📌 요구사항 요약

출발역과 도착역을 입력받고 { `최단 거리`, `최소 시간` } 중 선택한 조건에 맞는 경로를 조회한다.
<br/>

### 💡 스스로 판단한 규칙

- [ ] line은 현재 어떤 기능에도 쓰이지 않고 있다.
- [ ] 초기 정보로 주어진 역들은 모두 이어져있어서, 이어져있지 않은지는 판단하지 않는다.
- [ ] 데이크스트라 알고리즘 직접 구현 없이 `jgrapht`를 쓰면 된다.
  <br/>

## 📝 구현할 기능 목록

### 초기 역, 노선, 구간 정보 등록 기능

- [ ] 초기에 주어진 역과 노선 정보를 `Station`과 `Line`에 등록한다.
- [ ] `jgrapht`를 이용해 `최단 거리` 및 `최소 시간` 경로 그래프를 각각 만든다.
- [ ] 추후 기능 확장을 고려해 `Subway`라는 객체로 관리한다.

### 메인 화면에서 경로 조회를 계속 할지 입력받는 기능

- [ ] 메인화면 및 기능 목록을 출력한다.
- [ ] 원하는 기능 입력 요청 문구를 출력한다.
- [ ] 선택한 기능을 입력받는다.
    - [ ] `1`이나 `Q`인지 검증한다.

### 경로 조회 기능

- [ ] `경로 기준` 목록을 출력한다.
- [ ] 조회할 `경로 기준` 입력 요청 문구를 출력한다.
- [ ] 조회할 `경로 기준`을 입력받는다.
    - [ ] `1` 또는 `2`인지 검증한다.
- [ ] `출발역` 입력 요청 문구를 출력한다.
- [ ] `출발역`을 입력받는다.
    - [ ] 존재하는 역이 아니라면 에러 메시지를 출력하고 경로 기준부터 재입력받는다.
- [ ] `도착역` 입력 요청 문구를 출력한다.
- [ ] `도착역`을 입력받는다.
    - [ ] 존재하는 역인지 검증한다.
    - [ ] `출발역`과 다른지 검증한다.
- [ ] 선택한 조건에 맞게 경로를 조회한다.

### 경로 출력 기능

- [ ] 조회 결과를 출력한다.
- [ ] 메인 화면으로 돌아간다.
